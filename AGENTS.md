# AGENTS.md — ReVance Downloader (rd_manager)

## Project Identity
- Flutter app (Dart 3.10+, Material 3) named `rd_manager`
- Purpose: browse ReVanced GitHub releases, download APK/AAB, verify digest, install
- Private package (`publish_to: none`)

## Essential Commands
```bash
flutter pub get          # install deps
flutter analyze          # lint (flutter_lints + custom rules)
flutter test             # widget test only
flutter build apk --release   # signed via android/key.properties
```
- CI uses `flutter build apk --debug` (CI) and `--release --target-platform android-arm64` (release workflow)
- Release build tags: `RDmanager v1.0.${{ github.run_number }}`

## Architecture & Control Flow
- `main.dart` → `initApp()` → `WebSocketService.init()` (fire-and-forget background listener) → `MyApp`
- `MyApp` → permission/intro gate → `RepoSelector` (if repos exist) or `RepoDataList`
- `DownloadPage`/`AllAppsView` (lib/screens/) own a `DownloadCoordinator` and fetch assets via `GithubApi` (lib/services/); icons are filled in lazily via `fillMissingIcons`
- `DownloadCoordinator`: single active-download guard (`_isRunning`), watchdog Timer (60s inactivity timeout), `Completer`-based API, `ValueNotifier` progress/status
- `DownloadHistoryStore`: singleton sqflite, table `downloads(name PK, digest, path)`, `ConflictAlgorithm.replace`
- `RepoStorage` + `RepoData` (lib/models/): user repos in SharedPreferences; one built-in default from `secrets.dart`; read-only entries excluded from save
- `WebSocketService`: connects to `ntfyHost` from `secrets.dart`, filters messages containing `sequence_id`, calls `NotificationsService.showNotification`

## Project Layout (lib/)
- `main.dart` — app entry, permission gate, `RepoSelector` (switches DownloadPage ↔ AllAppsView by index, -1 = All Apps)
- `theme.dart` — `buildAppTheme(ColorScheme)` + `resolveAppSchemes()` (dynamic color + seed fallback); only place defining ThemeData
- `models/` — data types + persistence: `github_asset.dart` (`GithubAsset`, `packageName` heuristic), `repo_data.dart` (`RepoData`, `RepoStorage`, `loadRepoDataList`/`saveRepoDataList`), `models.dart` barrel
- `services/github_api.dart` — `GithubApi` (Dio client: `fetchLatestAssets(userName, repoName, {archFilter})`, `fillMissingIcons`, `close`), `AppMeta`, `fetchAppIcon` (Aptoide metadata lookup)
- `screens/` — `download_page.dart`, `all_apps_view.dart` (both use `AllAppsEntry`-style view models and shared widgets), `repo_data_list.dart` (repo CRUD + search), `intro_screen.dart`
- `widgets/` — shared UI via `widgets.dart` barrel: `AppSearchBar`, `AppIcon`, `AssetListItem`, `showAssetActionSheet`, `showDownloadProgressDialog`, `EmptyState`, `RepoDrawer`
- `utils/format.dart` — `formatBytes`
- legacy flat files (`download_page.dart`, `repo_data.dart`, `app_meta.dart`, `search_bar.dart`, `intro.dart`) were removed — screens live in `screens/`, models in `models/`

## Key Files
- `lib/secrets.dart` — auto-generated in CI from `secrets.ENVS` base64 secret; contains `ntfyHost`, `userName1`, `repoName1`
- `android/key.properties` — **not in repo**; created from `key.properties.example` + keystore; CI writes it from `KEYSTORE_BASE64` secret
- `android/gradle.properties` — 8G heap, caching on, Jetifier on (legacy), `android.newDsl=false`, `android.builtInKotlin=false`

## Naming & Conventions
- Package import: `package:rd_manager/<path>.dart` (e.g. `models/models.dart`, `screens/download_page.dart`, `widgets/widgets.dart`)
- Private members prefixed `_`
- Singletons use `._()` + `instance` factory (e.g., `DownloadHistoryStore`)
- Search: `AppSearchBar` widget (clear button built in) + `_searchQuery` state + `_filteredAssets` / `_filteredEntries` / `_filteredRepos` getters per screen

## Testing
- Single `test/widget_test.dart`; only verifies `MyApp` builds and renders `Scaffold`
- No unit/integration tests for coordinator, storage, or network layer

## Gotchas / Non-Obvious
1. `secrets.dart` is generated by CI (`echo "${{ secrets.ENVS }}" | base64 -d > lib/secrets.dart`) — **missing at dev time**; local dev must create it manually with the three constants or the app will fail at compile time
2. `DownloadCoordinator.startDownload` returns a `Future` that completes on finish/cancel/timeout; caller must `await` to observe final result
3. `cancelDownload()` calls `_finish()` synchronously — not safe to call twice; guarded by `_isCancelled`
4. `RepoStorage.load()` inserts the default repo at index 0 and removes duplicates by case-insensitive match
5. `IntroScreen._onIntroEnd` navigates with `pushReplacement(MaterialPageRoute(builder: (_) => const MyApp()))` — re-creates the whole app widget
6. Android `minSdk`/`targetSdk` come from `flutter.minSdkVersion`/`flutter.targetSdkVersion` (no hardcode in build.gradle.kts)
7. `lib/secrets.dart` is gitignored? verify — if not, do not commit real values
8. `download_coordinator.dart` has `_finish()` body not shown in truncated read — check before editing completion logic
9. `GithubApi.fetchLatestAssets` arch-filter: per-repo view keeps only arm64/universal/v8a assets; aggregated All Apps view keeps every apk/aab (`archFilter: false`)
